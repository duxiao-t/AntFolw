## 本轮定下的决策

- **D1 选择器门禁**：列表端点收窄 DTO（去掉登录账号、保留工号），按 id 的端点与管理端不动 → `D-20260924-picker-list-narrow-dto`
- **D2 隐藏字段选项**：按"调用者在这次流程上的节点"判（用 `t_task` 推节点），不是"任一节点隐藏就一律拒"（那会误伤本节点可见的审批人）
- **D3 流程监控**：5 条裸 SQL 全部按**实例**的发起人/发起部门注入范围，空范围恒假；outbox 显式限定 `aggregate_type`
- **D4 数据源引用**：只拦**新增**绑定（新旧 schema 的差集），撤销引用不妨碍已绑定的表单保存——表单 1/14 正是这个状态
- **D5 存量角色权限**：只补文档 + 守护测试 → `D-20260924-v40-legacy-permission-conversion`
- **D6 落地**：开 PR 到 main，让 CI 跑三端
- **D7 文档**：本文件 + PROJECT 的版本号与选择器不变量；三个历史快照加"已过期"抬头
- **D8 台账**：先在真库/隔离栈复核 V49，`table_list` 明细按列展开以后再说
