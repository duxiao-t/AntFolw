## 固定实施规则

1. P4：非全局管理员ALL/CUSTOM与当前公司相交，业务归属取行内快照；NULL/inferred须确认，
   普通正文隔离，旧草稿保留待确认提示。本人/任务例外不扩大管理、报表和导出权限；
   已关联附件按可读业务关联授权，未关联文件保留owner访问。后台worker明确豁免。
   新受控查询必须登记范围、专用授权SQL或自助/内部豁免。详见 `p4-company-isolation-matrix.md`。
   历史确认逐条有据，事务/行锁/更新行数=1，不按今天部门猜、不默认公司1。
2. P2：约束rules→props→既有默认值，公共fixture覆盖26类、空值、0/false、明细行作用域、
   检查项照片、矩阵、媒体READY/maxCount/可信时长、checkbox标签及版本固定；
   SQL保持既定脱敏。历史只读不重验、未知属性不丢。删除桌面未调用的FieldType.validate，
   收敛现有校验入口。文件增加可选durationSeconds，受时长约束的旧媒体再次提交时补测。
3. P3：实例/任务/动作/操作者守卫，统一先实例后任务锁序，保留版本保护；
   撤回修改保持RUNNING+__rework__。V2为生产必需，新实例不回落V1。
   生产运行/重提实例、关联待办、可恢复作业全为零才删legacy写路径并统一join；
   缺证据则保留兼容、明确登记待退役，不阻塞其他开发，不宣称H4=1。
4. P5：企微既有作业加领取令牌与租约（120秒/30秒续租），批次写入核验持有权、失租停止；

   共用附件、草稿、组织能力移至领域，移动controller保留适配。
   生产业务传输类型同源，移动不引入Umi；OIDC登录保持同步。
5. 分包相关用例通过后直接继续，最终串行全量；保存旧镜像，备份并独立恢复数据库/附件，

- GET `/api/workflow-monitor/outbox`：默认DEAD，records/total/page/size，最多100条；
