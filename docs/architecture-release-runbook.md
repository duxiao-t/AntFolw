# 全路线发布包

仅交付本机验收及生产操作步骤；生产尚未执行。对应分支 `feat/architecture-completion`，
基线 `c14f055`。最终提交、镜像 ID、校验结果见同批发布记录。

已验收产物包为 `backend/target/architecture-delivery-20261015.tar.gz`。
在独立目录解包后，先核对 `RELEASE.json` 的提交及摘要，再使用包外密钥文件执行
`docker compose --env-file /secure/antflow.env build backend web`。进入生产前仍需完成下面维护窗口、
备份/恢复和历史归属预检；包中不含本机 `.env`、业务数据或备份。

## 发布前

1. 确认生产发布窗口与操作人，停止写入及后台消费者。数据库备份和 MinIO 附件快照保存在仓外，
   独立恢复核对实例、填报、附件行数及对象 SHA256；旧 backend/web 镜像必须先留不可变 tag。
2. 用只读连接执行 `infra/sql/workflow-v1-preflight.sql`，保留目标环境、时间和查询结果。
   本批保留 V1 写路径，任何本机零存量结果都不构成生产退役证据。
3. 盘点 `company_id IS NULL` 和 `company_inferred=true` 的历史数据。普通员工的正文、附件及待办
   将被关闭，草稿仍显示“归属待确认”；确认动作遵守既有 `p4a-rollout-runbook.md`，
   要有来源证据、事务行锁及更新行数核验，不能按当前部门自动回填。
4. 核对现有企微 PENDING/RUNNING 作业。升级后 PENDING 和过期租约作业自动重新拉取，
   幂等继续写入；先停止旧版本 worker，避免不懂租约的旧程序仍写组织。
5. BI 继续只允许全局可信账号；公司管理员使用应用报表。执行既有
   `infra/sql/bi-readonly-role.sql` 的数据库角色验证，不将全局 BI 凭据发给公司管理员。

## 发布顺序与验收

同步发布后端、桌面和移动构建产物。Flyway 按顺序执行：

| 版本 | 内容 | 兼容边界 |
| --- | --- | --- |
| V56 | checkbox BI 标签解析与 multi_select 同义 | 不扩大值脱敏白名单，不删除历史快照 |
| V57 | 附件可选可信时长 | 旧媒体正式再提交时补测；ffprobe 缺失则拒绝受限媒体提交 |
| V58 | 企微领取令牌与租约字段 | 120 秒租约、30 秒续租，停止旧 worker 后才启用新 worker |

启动时要求 V2 bean，所有新实例写 `engine_version=2`；旧 V1 流程继续兼容。
镜像须包含 `ffmpeg`、`ffprobe` 和中文字体。

执行 `infra/sql/architecture-release-preflight.sql`，确认 V58、健康 UP、
新能力 `workflow:outbox:retry` 默认 SELF；不得自动授给非管理员。
界面验收使用真实双公司账号：A 管理列表/count/详情/报表/导出/选项/附件不可见 B，
已确认本人历史及跨公司审批仍按原关系可用，NULL/inferred 记录不以本人或任务关系绕过。
正式提交超长媒体应拒绝并保留草稿；终态、旧轮次和重复任务动作不得产生新任务或历史。

监控页“失败消息”只回元数据及脱敏提示，重放接口仅允许 DEAD→PENDING，
保留 UUID、载荷及稳定投递键。用一条专用失败事件验证成功重放和重复请求冲突；
缺能力 403、公司越界 404，审计中应有一次成功操作。
渠道为至少一次投递，接收端继续按事件键幂等。

企微故障注入与 OIDC 自动用例不等于真实企业账号联调；生产窗口按配置执行一轮真实账号免登、
同步及通知，核对重启恢复和缺失成员停用仅发生于完整拉取之后。

## 回退

优先停止新 worker 后回滚 backend/web 镜像，保留新增列和 V56 视图，Flyway 历史不倒退。
V57/V58 都为加列；旧程序不能校验可信媒体时长，也不能遵守企微租约，因此回滚期间关闭
媒体正式提交及企微同步。部署工具若因数据库版本领先镜像而拒绝启动，维持维护窗口，
使用已经演练的原库及附件快照恢复；不要删除 flyway_schema_history 或修改历史迁移。
数据库和附件必须作为同一恢复点回退，恢复前确认窗口后写入的处理方式。

## 本批保留

V1 退役须生产运行/重提实例、关联待办和可恢复作业全部为零，届时再删 legacy 写路径并统一 join；
当前 H4 仍为 2。人工归属确认和生产窗口不由本机验收代替。
